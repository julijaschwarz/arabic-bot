# Тренажёр арабского алфавита в Telegram

Личный бот: каждый день присылает 10+ заданий на буквы, их формы, счёт ٠–٩ и
распознавание букв внутри слов. Задания собираются программно, поэтому они не
кончаются. Если активности нет 6 часов, бот напомнит: «Пора повторить арабский!».

## Быстрый старт

1. Получите токен у [@BotFather](https://t.me/BotFather): `/newbot`, дальше по подсказкам.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot) — это число.
3. Создайте `.env`:

```bash
cp .env.example .env
```

Впишите в него `BOT_TOKEN` и `ALLOWED_USER_IDS` (ваш ID). Остальное можно не трогать.

4. Запустите:

```bash
make up
```

5. Прогрейте кэш картинок — один раз, несколько секунд:

```bash
make warm-cache
```

После этого напишите боту `/start`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/go` | начать занятие |
| `/more` | ещё 5 заданий |
| `/stats` | прогресс, круг по алфавиту, трудные буквы |
| `/letters` | шпаргалка: все 28 букв с формами |
| `/digits` | шпаргалка: цифры ٠–٩ с названиями |
| `/settings` | время рассылки, число заданий, напоминания |
| `/stop` | закончить занятие |

Настройки меняются прямо в чате: `/settings time 09:00`, `/settings count 12`,
`/settings notify off`.

## Как отвечать

Почти везде ответ пишется текстом — по-русски или латиницей. Проверка терпимая:
«ба», «баа», «Ба!», `ba`, `baa`, `bāʼ` — всё засчитывается. Кнопки появляются
только там, где ответ физически не набрать: когда нужно выбрать арабский глиф.

В разборе слова называйте буквы через пробел — «кяф та алиф ба» — или напишите
слово целиком: «kitab». Оба варианта верны.

Транслитерации арабских названий пересекаются: «ха» — это и ح, и خ, и ه. Такие
ответы засчитываются, а разницу бот поясняет в подсказке. То же с числительными:
«саляса», «таляса» и «талата» — всё ٣.

## Как это устроено

```
src/arabic_bot/
├── domain/      28 букв с формами, цифры с названиями, словарь, разбор на глифы
├── exercises/   реестр генераторов + 16 типов заданий + проверка ответов
├── learning/    круг по алфавиту, интервальное повторение, сборка сессии
├── media/       отрисовка слов с подсветкой буквы
├── storage/     SQLite: пользователи, прогресс, сессии, история ответов
├── bot/         хендлеры Telegram, клавиатуры, тексты
└── scheduler/   утренняя рассылка и напоминания
```

**Круг по алфавиту.** Все 28 букв проходят по разу за круг, каждый день в фокусе
6 букв. Буквы, на которых были ошибки, возвращаются раньше остальных
(упрощённый SM-2), но не больше трети мест отдаётся повторению — иначе круг не
закрывался бы. На практике круг занимает около пяти дней.

**Словарь.** Задания генерируются, но слова настоящие — они лежат в
[`words.yaml`](src/arabic_bot/data/words.yaml) (206 слов). Комбинации
«слово × буква × тип задания» дают тысячи неповторяющихся упражнений. Чтобы
добавить слова, допишите строки в этот файл — код менять не нужно.

**Картинки.** Слово раскладывается на глифы вручную (`domain/shaping.py`), поэтому
позиция каждой буквы известна и её можно подсветить цветом. Таблица форм строится
из имён Unicode, а не захардкожена. Лигатура لا обрабатывается отдельно.

**Расписание и спящий ноутбук.** APScheduler по умолчанию отбрасывает задание,
опоздавшее больше чем на секунду, — а на засыпающем компьютере опаздывает каждое.
Поэтому у заданий большой запас по опозданию, а утренняя рассылка не полагается
на срабатывание ровно в 09:00: на каждой проверке простоя бот смотрит, уходило ли
занятие за сегодня, и досылает его. Если вы уже позанимались, рассылка молчит.

## Как добавить новый тип задания

Один файл в `src/arabic_bot/exercises/generators/` — и всё:

```python
from ...domain.models import AnswerMode, Exercise
from ..base import ExerciseGenerator, GenContext, letter_answers
from ..registry import register


@register
class MyExercise(ExerciseGenerator):
    id = "my_exercise"
    title = "Моё задание"
    weight = 10          # относительная частота в сессии

    def generate(self, ctx: GenContext) -> Exercise | None:
        letter = ctx.shuffled_letters()[0]
        return Exercise(
            generator_id=self.id,
            prompt="Вопрос?",
            display=letter.char,
            answer_mode=AnswerMode.TEXT,
            accepted=letter_answers(letter),
            explanation="Пояснение к правильному ответу",
            focus_letters=(letter.id,),
        )
```

Реестр найдёт файл сам, планировщик начнёт выдавать задание, а тесты
автоматически проверят новый тип: у каждого генератора проверяется, что
заявленный правильный ответ проходит собственную проверку.

## Разработка

```bash
make test
```

Тесты гоняют каждый генератор по 500 раз и проверяют, что задание валидно, а его
правильные ответы засчитываются. Отдельно проверяются нормализация ответов,
покрытие круга всеми 28 буквами, арифметика повторений, полный урок через
настоящую SQLite и настройки планировщика — именно их отсутствие однажды
привело к молча пропущенным напоминаниям. Сеть не нужна.

Локально без Docker:

```bash
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
PYTHONPATH=src .venv/bin/python -m pytest tests -q
```

Полезные команды: `make logs`, `make shell`, `make backup`, `make restart`.

## Сервер

Бот работает на VPS и обновляется сам: push в `main` → GitHub Actions гоняет тесты →
сервер подтягивает изменения и пересобирает контейнер. Ручное вмешательство нужно
только для `.env` — он в git не попадает.

Ключи деплоя лежат в секретах репозитория (`DEPLOY_SSH_KEY`, `DEPLOY_HOST`,
`DEPLOY_USER`). На сервере этот ключ привязан к forced command и умеет ровно одно —
запустить `~/deploy.sh`; shell по нему получить нельзя. Репозиторий публичный,
поэтому у workflow нет триггера `pull_request`: иначе через форк можно было бы
добраться до секретов.

Развернуть с нуля на новом сервере:

```bash
git clone https://github.com/julijaschwarz/arabic-bot.git ~/arabic-bot
cd ~/arabic-bot
cp .env.example .env   # впишите BOT_TOKEN и ALLOWED_USER_IDS
make up
make warm-cache
```

Бот сам поднимается после перезагрузки (`restart: unless-stopped`). База и кэш лежат
в томе `arabic-data` и переживают пересборку образа; `make backup` выгружает базу
в `./backup`. На машине с 512 МБ памяти нужен swap — без него сборка образа уходит в OOM.

## Настройки

Все параметры — в `.env`, ничего не хардкодится и не пишется на хост.
Зависимости внутри образа стоят в отдельном venv `/opt/venv`.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `ALLOWED_USER_IDS` | пусто | кому можно пользоваться; пусто — всем |
| `TZ` | `Europe/Moscow` | часовой пояс |
| `DAILY_TIME` | `09:00` | во сколько приходит первое задание дня |
| `DAILY_TASK_COUNT` | `10` | заданий в сессии |
| `FOCUS_LETTERS_PER_DAY` | `6` | букв в фокусе дня |
| `IDLE_HOURS` | `6` | через сколько часов тишины напомнить |
| `QUIET_HOURS` | `22:00-08:00` | когда не беспокоить |
| `IMAGES_ENABLED` | `true` | картинки слов |
